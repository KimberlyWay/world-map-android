# Карта мира — простое учебное Android-приложение

Учебное приложение на Kotlin с XML-разметкой. Один экран: большая интерактивная карта мира. Карту можно двигать и приближать от всей планеты до отдельных домов, искать на ней места и узнавать, что находится в точке, на которую нажали.

Тема работы — **подключение карты к мобильному приложению**. Используются открытая библиотека карт **MapLibre**, бесплатные карты **OpenFreeMap** (данные OpenStreetMap) и API геокодирования **Nominatim**. Ключи API, регистрация и банковская карта не нужны.

## 1. Что умеет приложение

- Показывает карту всего мира. Жесты: перетаскивание, щипок для масштаба, поворот.
- Кнопки «+» и «−» для приближения (удобно в эмуляторе), кнопка «Весь мир», выбор вида карты.
- Четыре вида карты: обычная, яркая, светлая, тёмная. Выбор запоминается.
- Подписи по-русски; где русского названия нет, оно показано латиницей или как в оригинале.
- Поиск по названию или адресу: список до пяти вариантов, перелёт к выбранному месту и красная метка.
- Нажатие на карту: метка и карточка с названием, адресом и координатами. Нажатие на координаты копирует их.

Чего нет: определения вашего местоположения, построения маршрутов, работы без интернета, своего сервера и базы данных.

## 2. Как пользоваться

1. Открыть приложение при включённом интернете. Появится карта мира.
2. Приближать щипком или кнопками «+» / «−». Кнопка с глобусом возвращает общий вид.
3. Ввести в строку поиска, например, `Казань` или `Эйфелева башня`, нажать значок лупы или «Поиск» на клавиатуре.
4. Нажать на любую точку карты, чтобы узнать, что там. Чем сильнее приближена карта, тем подробнее ответ: при общем виде это страна, вблизи — улица и дом.
5. Кнопка со слоями меняет вид карты.

## 3. Как подключена карта

Это главная часть задания. Подключение состоит из пяти шагов.

**Шаг 1. Зависимость** в `app/build.gradle.kts`:

```kotlin
implementation("org.maplibre.gl:android-sdk:11.13.5")
```

И в `gradle.properties` строка `android.useAndroidX=true`: библиотека использует AndroidX.

**Шаг 2. Разрешение на интернет** в `AndroidManifest.xml`:

```xml
<uses-permission android:name="android.permission.INTERNET" />
```

Библиотека сама объявляет доступ к местоположению; приложение его не использует и убирает через `tools:node="remove"`.

**Шаг 3. Виджет карты** в разметке `activity_main.xml`:

```xml
<org.maplibre.android.maps.MapView
    android:id="@+id/mapView"
    android:layout_width="match_parent"
    android:layout_height="match_parent" />
```

**Шаг 4. Код в `MainActivity.kt`:**

```kotlin
MapLibre.getInstance(this)               // обязательно до setContentView
setContentView(R.layout.activity_main)
mapView.onCreate(savedInstanceState)
mapView.getMapAsync { map ->             // карта готова
    map.setStyle(Style.Builder().fromUri("https://tiles.openfreemap.org/styles/liberty"))
}
```

**Шаг 5. Жизненный цикл.** Экран должен передавать карте вызовы `onStart`, `onResume`, `onPause`, `onStop`, `onSaveInstanceState`, `onLowMemory`, `onDestroy`. Без этого карта может остаться пустой или приложение упадёт.

### Откуда берётся картинка

Адрес **стиля** — это JSON-файл, где описано, откуда загружать данные и какими цветами их рисовать. Данные приходят **векторными тайлами**: карта мира разрезана на квадраты, и телефон скачивает только те, что видны при текущем масштабе. Рисует их сам телефон, поэтому подписи остаются чёткими при любом приближении, а стиль и язык можно менять в приложении.

Подпись об источнике в левом нижнем углу (кнопка «i») обязательна по условиям OpenStreetMap и OpenFreeMap — не убирайте её.

## 4. Как работает API поиска

Карта и поиск — **два разных сервиса**. Поиск выполняет REST API Nominatim: приложение отправляет обычный HTTPS-запрос `GET` и получает JSON.

| Действие | Запрос | Что возвращается |
|---|---|---|
| Поиск по названию (прямое геокодирование) | `https://nominatim.openstreetmap.org/search?format=jsonv2&limit=5&accept-language=ru&q=Казань` | Список мест: название, адрес, широта, долгота, границы |
| Что в этой точке (обратное геокодирование) | `.../reverse?format=jsonv2&accept-language=ru&lat=55.79&lon=49.11&zoom=10` | Одно место или ошибка, если названия нет |

Порядок работы (`MainActivity.kt`):

1. `GeoApi` собирает адрес запроса.
2. `GeoClient` отправляет его в фоновом потоке, чтобы интерфейс не зависал.
3. `GeoApi` разбирает JSON в объекты `Place`.
4. В главном потоке камера перелетает к месту, ставится метка и открывается карточка.

Масштаб при перелёте зависит от размера объекта (поле `boundingbox`): страна показывается издалека, здание — крупно. Если нажать несколько раз подряд, учитывается только последний запрос.

**Правила Nominatim**, которые соблюдены в коде: не чаще одного запроса в секунду, запрос только по действию пользователя (без подсказок во время набора), название приложения в заголовке `User-Agent`. Это общий бесплатный сервер: для настоящего приложения с большим числом пользователей нужен другой.

## 6. Открытие в Android Studio

1. Открыть репозиторий, нажать `Code → Download ZIP` либо скачать исходники из раздела Releases.
2. Распаковать архив, например в `C:\Projects\WorldMap`.
3. В Android Studio: `File → Open`, выбрать папку, внутри которой лежит `settings.gradle.kts`. Не открывайте проект внутри ZIP.
4. Дождаться «Gradle sync». Первый раз нужен интернет: Studio скачает Gradle, плагины, библиотеку карты и Android SDK 35. Если Studio предложит обновить версии плагинов, откажитесь.
5. Запустить кнопкой Run на эмуляторе или телефоне, либо установить готовый APK из Releases.

Если в эмуляторе карта есть, а подписей нет, дело в программном режиме графики: в настройках виртуального устройства смените режим Graphics или запустите эмулятор с параметром `-gpu swangle_indirect`. На проверке в режиме `swiftshader_indirect` подписи не рисовались, в `swangle_indirect` и `guest` — рисовались.

В эмуляторе масштаб удобнее менять кнопками «+» / «−»; щипок имитируется перетаскиванием мышью с зажатым `Ctrl`. Набрать русский текст в поиске эмулятора можно после добавления русской раскладки в его настройках; названия латиницей тоже работают.

## 7. Сборка через GitHub Actions

`.github/workflows/android.yml` на каждый push в `main` запускает тесты, Android Lint и сборку APK. Готовый файл: вкладка **Actions** → последний зелёный запуск → **Artifacts** → `world-map-apk`.

Релиз с APK и ZIP исходников создаётся при отправке тега на `v`:

```text
git tag v1.0
git push origin v1.0
```

Второй workflow, `screenshot.yml`, запускается вручную (**Actions** → **Emulator screenshots** → **Run workflow**): ставит приложение на эмулятор и сохраняет снимки экрана. Их удобно вставить в отчёт.

## 9. Как изменить проект

- **Начальный вид карты.** Функция `worldCamera()` в `MainActivity.kt`: центр и масштаб.
- **Виды карты.** Список `MAP_STYLES` в `MapStyles.kt` и названия в `strings.xml`.
- **Метка.** Цвет и размер в `addPinLayer()`.
- **Число результатов поиска.** `SEARCH_LIMIT` в `GeoApi.kt`.
- **Тексты.** `strings.xml`.

## 10. Что можно удалить после скачивания

**Git и Gradle — разные инструменты.** Git хранит историю, Gradle собирает APK. Перед очисткой сохраните копию проекта и закройте Studio.

### Файлы GitHub, не нужные для локальной работы

| Что можно удалить | Последствие |
|---|---|
| `.git/` (есть, только если проект клонирован) | Пропадут история и связь с GitHub. Код останется. В ZIP этой папки нет. |
| `.github/` | Локальная сборка работает. Если удалить в репозитории, перестанут работать Actions и релизы. |
| `.gitignore`, `.gitattributes` | На приложение не влияют, нужны только Git. |
| `README.md` | Пропадёт только описание. |
| `RELEASE_NOTES.md` | Нужен только автоматическому релизу. |

### Можно очистить, создастся заново

| Что | Что произойдёт |
|---|---|
| `.gradle/`, `.kotlin/` | Следующая сборка будет дольше. |
| `build/`, `app/build/` | Исчезнут APK и отчёты. Нужный APK сначала скопируйте. |
| `.idea/`, `*.iml` | Studio пересоздаст настройки. |
| `local.properties` | Studio заново найдёт SDK. |

### Нельзя удалять, без них проект не соберётся

- `app/src/main/` целиком, `app/build.gradle.kts`;
- `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties` в корне;
- `gradle/wrapper/`, включая `gradle-wrapper.jar`, а также `gradlew` и `gradlew.bat`.

`app/src/test/` на работу приложения не влияет: там только тесты.

## 11. Проверки и ограничения

В GitHub Actions выполняются юнит-тесты (адреса запросов, разбор ответов, расчёт масштаба и координат), Android Lint и сборка. Тесты не обращаются к сети.

Ограничения: без интернета новые участки карты и поиск не работают; бесплатные сервисы OpenFreeMap и Nominatim не гарантируют постоянную доступность — проверьте приложение перед показом; названия и адреса берутся из OpenStreetMap и могут быть неполными.
