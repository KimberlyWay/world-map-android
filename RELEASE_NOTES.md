Первый выпуск учебного приложения «Карта мира».

- Большая карта мира: перетаскивание, приближение жестами и кнопками.
- Поиск города, страны или адреса через API Nominatim.
- Нажатие на карту показывает название места, адрес и координаты.
- Четыре вида карты, подписи по-русски. Ключи API и регистрация не нужны.

Вложения: установочный APK и ZIP исходников с README для Android Studio.

Приложению нужен интернет. Используется отладочная подпись.
